# **Customer Churn Data Science Project**

This project focuses on analyzing customer churn patterns using
data visualization and a simple interactive chatbot.

# **Key Features:**
- Churn distribution analysis
- Visualization dashboard
- Correlation heatmap
- Rule-based chatbot

# **Tools Used:**
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
